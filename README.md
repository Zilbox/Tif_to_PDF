# 🖨️ TIF → PDF Конвертер

Программа для пакетной конвертации файлов **TIF/TIFF** в формат **PDF** с сохранением исходной структуры папок.  
Создана для быстрого и надёжного преобразования больших объёмов документов.

---

## ⚡ Возможности

- **Пакетная обработка** – конвертирует все `*.tif` и `*.tiff` файлы в выбранной папке (включая вложенные).
- **Режим одного файла** – можно выбрать конкретный TIF-файл для конвертации.
- **Сохранение структуры** – относительные пути исходных папок полностью восстанавливаются в папке назначения.
- **Обработка ошибок** – автоматические повторные попытки (3 раза) при сетевых сбоях (ошибка `64`).
- **Очистка имени** – автоматически удаляет недопустимые для Windows символы (`[<>:"/\|?*]`) из имени файла.
- **Графический интерфейс** – удобное окно на Tkinter для выбора источника, папки назначения и режима работы.

---

## 🖥️ Как использовать

1. **Запустите приложение** (`TifToPDF.exe` или скрипт `main.py`).
2. **Выберите режим**:
   - `Папка` – обработать все TIF-файлы в указанной директории и её подпапках.
   - `Один файл` – конвертировать выбранный TIF-файл.
3. **Укажите папку назначения** (куда сохранять готовые PDF).
4. Нажмите **«Конвертировать»** – процесс начнётся.

Результат будет сохранён с тем же именем, но с расширением `.pdf` в соответствующей подпапке внутри выходной директории.

---

## ⚠️ Примечания

Программа не изменяет исходные TIF-файлы.

Для больших изображений автоматически снимается ограничение на размер пикселя (Image.MAX_IMAGE_PIXELS = None).

При конвертации одного файла относительный путь не создаётся – PDF сохраняется прямо в корень папки назначения.
